# 神經網路如何讓你看見世界

以繁體中文撰寫的大學部神經科學互動教材。

[開啟教材](https://yuehpengchen.github.io/neuroscience-networks/)

六個單元涵蓋皮質網路與連結、特徵與物件辨識、分散式表徵與降維、粗略編碼與選擇性、循環興奮與吸引子，以及抑制與競爭。以生活情境串起十二道選擇題，每個選項都有因果解釋；六道主觀反思不列入分數。六組原創 SVG 示意圖提供可操作的探索，開場與結尾則用同一張歧義圖回看知覺與信心。

## 使用方式

直接開啟 `index.html` 即可離線使用，也可由上述 GitHub Pages 網址使用。網頁適用於桌面與手機，支援鍵盤操作。

作答、重試、信心與反思只保存在使用者瀏覽器的 `localStorage`。沒有後端、追蹤程式、遠端字型或外部模型 API。網頁提供確認後清除本教材紀錄的功能。

## 教學來源與界線

教材依陳嶽鵬（Yueh-Peng Chen）的 *Networks* 課程投影片（38 頁）主題編排，文字、情境題及圖形為此互動教材重新撰寫與繪製，未重製投影片圖片。

互動數值是定性教學示意，不是量測資料或完整的神經生理模型。內容區分可評分的機制理解與沒有標準答案的主觀反思，也提示生物網路比示意圖更複雜。

## 部署

本儲存庫的 `main` 分支根目錄由 GitHub Pages 發佈。`.nojekyll` 讓單一 HTML 直接作為靜態頁面提供；更新 `index.html` 後，GitHub Pages 會重新部署。
